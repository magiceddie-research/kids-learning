# 學習基地 kids-learning

國小互動式闖關教材（三年級上學期：國語、數學、社會、自然）。

- 網址：https://magiceddie-research.github.io/kids-learning/
- 進度存在各裝置的瀏覽器中，可用「存檔碼」搬到其他裝置。
- 遊戲內只使用暱稱，請勿輸入真實姓名。
- 題目與文章為依各版本單元主題自編的練習，並非課本原文。

## 檔案結構
- `index.html`：入口
- `css/app.css`：樣式（各科主題）
- `js/app.js`：共用引擎（角色、計分、關卡、錯題本、存檔碼、家長專區）
- `js/labs.js`：自然互動實驗
- `data/*.js`：各科題庫與期末模擬考
